# 견적 총액 산정 범위

## Decisions

- 육상 기준 예상 총액(`estimateCost()`의 `totalMin/totalMax`: 다이빙 비용 + 장비 + 항공 + 숙소 패키지)과 리브어보드 기준 예상 총액(`liveaboardTotalMin/Max`: 항공 + 리브어보드 패키지)은 서로 합산하지 않고 항상 별도의 두 총액으로 계산·표시한다.
- 리브어보드 패키지 요금은 1박 단가에 여행 박수를 곱해 총액으로 낸다(`liveaboardPackageMin/Max`).

## Boundaries

- 리브어보드가 운항하는 목적지에서만 리브어보드 관련 필드가 계산되고, 화면에도 그 달에 운항할 때만 리브어보드 총액이 표시된다.
- 두 총액을 더해 하나의 "전체 예상 총액"을 만드는 것은 이 결정이 허용하지 않는다. 항공비는 두 총액에 각각 포함되어 이미 중복 계상 없이 독립적으로 완결된 금액이다.

## Why

리브어보드는 항공은 공유하지만 육상 숙소·육상 다이빙 비용을 공유하지 않는, 육상 다이빙과는 완전히 별도의 여행 형태다. 사용자가 human-review에서 "별도의 여행이다, 합치면 안 된다"고 확인한 뒤, 그럼에도 리브어보드로 갈 경우의 총액은 별도로 알고 싶다는 요청을 추가로 확인해 두 총액을 각각 독립적으로 완결되게 계산하기로 했다.

## Reconsider when

- 한 여행에서 리브어보드와 육상 숙박을 함께 쓰는(예: 리브어보드 며칠 + 육상 며칠) 혼합 일정을 지원하게 될 때.

## Still-rejected alternatives

- 리브어보드 요금을 육상 기준 총액에 더해 하나의 총액으로 보여주는 방식 — 실제로 선택하지 않는 조합(육상 숙소 + 리브어보드)이 총액에 섞여 기각.
- 리브어보드 요금을 참고 정보로만 표시하고 별도 총액을 만들지 않는 방식 — 사용자가 리브어보드 기준 총액도 별도로 필요하다고 확인해 기각.
