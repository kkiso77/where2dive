# 지도 렌더링

## Decisions

- 지도는 Leaflet과 OpenStreetMap 타일로 렌더링한다.
- 개별 다이빙샵이나 목적지의 상세 위치 정보는 구글맵 장소 링크로 연결해 사용자가 외부에서 확인하게 한다.

## Boundaries

- 이 결정은 앱이 직접 그리는 지도에만 적용된다. 외부 링크로 구글맵을 여는 것은 제한하지 않는다.

## Why

구글맵 JavaScript API는 클라우드 프로젝트 생성, API 키 발급, 결제 수단 등록이 모두 필요하다. 키가 없으면 지도가 아예 뜨지 않아 강의용 환경에서 검증이 막힌다. Leaflet + OSM은 키 없이 즉시 동작하고 마커 표시와 줌·이동이라는 필요 기능을 충족한다.

## Reconsider when

- 스트리트뷰, 장소 상세 정보, 경로 탐색처럼 OSM으로 대체할 수 없는 구글 고유 기능이 필요해질 때.

## Still-rejected alternatives

- 구글맵 JavaScript API — API 키와 결제 수단 없이는 렌더링 자체가 실패해 개발·검증 진입 장벽이 된다. 운영 환경에서 키 관리 체계가 갖춰지면 다시 검토한다.
