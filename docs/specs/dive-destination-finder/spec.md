# 시즌별 다이빙 목적지 탐색과 견적 비교

## 배경

1인 독립 다이버가 1년 휴가 계획을 세우면서, 특정 시기에 다이빙 환경이 좋은 해외 목적지와 예상 비용을 알아본다. 지금은 카페·블로그에서 사이트 정보를 찾고 구글맵에서 다이빙샵 요금을 따로 확인해야 해서, 정보가 흩어진 만큼 매번 검색에 시간을 쓴다.

이 작업 단위는 제품의 핵심 루프(조건 입력 → 후보지와 견적 비교 → 조건 재조정) 전체를 한 화면에서 완결시킨다. 화면 구조와 동작은 사용자 검토를 거쳐 승인된 [prototype.html](prototype.html)을 근거로 삼는다.

## 사용자에게 보이는 결과

한 화면에서 다음이 이루어진다.

**조건 입력**
사용자는 여행 월, 여행 기간(일수), 지역 필터, 다이빙 스타일 관심사를 지정한다. 다이빙 횟수는 기간에서 자동 추정된 값이 기본으로 제시되고, 사용자가 직접 조정할 수 있다.

**후보지 결과**
조건에 맞는 다이빙 목적지가 지도 위 마커와 카드 목록으로 동시에 표시된다. 카드 목록은 국가별로 묶이고, 국가 그룹은 접었다 펼 수 있다. 그룹 내부는 인천에서 가까운 순으로 정렬된다. 그 달에 다이빙하기 좋은 추천 목적지와, 조건에 안 맞는 비추천 목적지가 각각 별도 구획으로 항상 함께 표시된다. 각 후보지 카드는 해당 월의 컨디션 등급과 그렇게 판단한 이유, 다이빙 스타일 특성, 공항에서 다이빙 지역까지 가는 이동 방법 요약, 예상 총비용을 보여준다.

**상세 견적**
후보지를 선택하면 견적이 항목별로 펼쳐진다. 다이빙 비용(구간별 1다이브 단가 전체 요금표와 현재 적용 구간), 장비 대여료, 리브어보드 옵션(해당 지역에 운항하는 경우), 인천 출발 항공 요금대(직항 여부, 경유 시 경유 공항과 최종 목적지 공항), 공항에서 다이빙 지역까지 가는 구체적인 이동 방법, 숙소 요금대(다이빙샵 패키지 포함형과 별도 숙박형 각각)가 모두 드러난다. 해당 월에 그 컨디션 등급을 받은 이유도 함께 표시된다.

**나란히 비교**
후보지를 여러 곳 선택해 항목별로 나란히 놓고 비교할 수 있다. 컨디션, 다이빙 스타일, 비용 항목이 같은 축에 정렬되어 차이가 바로 보인다.

**조건 재조정**
조건을 바꾸면 페이지 이동 없이 결과만 갱신된다. 선택해둔 비교 대상은 조건 변경 후에도 유지되며, 새 조건에서 해당 목적지가 후보에서 빠지면 그 사실이 사용자에게 드러난다.

## 승인된 범위

- 조건 입력, 지도, 카드 목록, 상세 견적, 나란히 비교가 한 화면에 있다.
- 다이빙 목적지 데이터는 저장소 안의 큐레이션 데이터에서 온다.
- 지도는 Leaflet과 OpenStreetMap으로 그린다.
- 초기 데이터 범위는 동남아 목적지로 한정한다.

## 수용 기준

1. 여행 월과 기간을 입력하면 해당 월에 다이빙 가능한 목적지가 인천에서 가까운 순으로 지도와 목록에 함께 표시된다.
2. 같은 목적지가 지도 마커와 카드 목록 양쪽에 나타나며, 한쪽에서 선택하면 다른 쪽에서도 선택 상태가 드러난다.
3. 여행 기간을 입력하면 이동일을 제외한 다이빙 횟수 기본값이 제시되고, 그 값을 조정하면 견적 총액이 즉시 바뀐다.
4. 다이빙 횟수를 멀티다이브 할인 구간을 넘어서게 조정하면, 할인된 단가가 적용되고 어떤 구간이 적용됐는지 화면에서 확인된다.
5. 후보지를 선택하면 다이빙 비용, 장비 대여료, 항공 요금대, 숙소 요금대가 각각 별도 항목으로 표시된다.
6. 리브어보드가 운항하는 목적지에서는 리브어보드 옵션과 요금대가 표시되고, 운항하지 않는 목적지에서는 해당 항목이 나타나지 않는다.
7. 숙소는 다이빙샵 패키지 포함형과 별도 숙박형이 각각 구분되어 표시된다.
8. 항공 요금대는 인천 출발 기준이며, 경유가 필요한 목적지는 경유 사실이 표시된다.
9. 다이빙 스타일 관심사(초급자 추천, 조류, 드리프트, 대물, 매크로)로 후보지를 걸러낼 수 있고, 걸러낸 결과가 지도와 목록에 동시에 반영된다.
10. 지역 필터로 국가 단위 범위를 좁힐 수 있다.
11. 후보지 두 곳 이상을 선택하면 컨디션·스타일·비용 항목이 같은 축에 정렬된 비교 화면을 볼 수 있다.
12. 조건을 바꿔도 페이지가 이동하지 않고 결과만 갱신되며, 선택해둔 비교 대상은 유지된다.
13. 새 조건에서 비교 대상 목적지가 후보에서 제외되면, 제외됐다는 사실이 사용자에게 드러난다.
14. 조건에 맞는 목적지가 하나도 없으면 그 사실과 조건을 어떻게 바꾸면 되는지가 안내된다.
15. 모든 금액에는 조사 시점 기준의 참고가라는 점과 그 기준 시점이 함께 표시된다.
16. 각 목적지의 다이빙샵 정보는 구글맵 장소 링크로 연결되어 사용자가 직접 확인할 수 있다.
17. 후보지 목록은 국가별로 묶여 표시되고, 국가 그룹은 접었다 펼 수 있다.
18. 각 후보지 카드와 상세 견적에는 해당 월에 그 컨디션 등급을 받은 이유가 한 줄로 표시된다.
19. 다이빙 비용은 1～2회, 3～4회, 5～9회, 10회 이상 네 구간의 전체 요금표로 제시되고, 현재 다이빙 횟수에 적용된 구간이 표시된다.
20. 각 목적지의 공항에서 실제 다이빙 지역까지 가는 이동 수단과 소요 시간이 카드에는 요약으로, 상세 견적에는 자세히 표시된다.
21. 그 달에 조건이 맞지 않는 비추천 목적지도 추천 목적지와 별도 구획으로 항상 함께 표시된다. 조건 필터로 걸러져 아예 후보에 들지 못한 목적지와는 구분된다.

## 확정된 제약과 근거

- **데이터는 저장소 내 큐레이션 정적 데이터를 쓴다.** 월별 다이빙 컨디션은 어떤 외부 API로도 제공되지 않아 어차피 사람이 조사해야 하고, 소스를 하나로 통일하는 편이 일관성과 검증 비용 면에서 유리하다. → [travel-data-source](../../decisions/travel-data-source.md)
- **지도는 Leaflet + OpenStreetMap을 쓴다.** 구글맵 JavaScript API는 키와 결제 수단 없이는 렌더링 자체가 실패해 검증이 막힌다. → [map-rendering](../../decisions/map-rendering.md)
- **금액은 단일 값이 아니라 요금대로 제시한다.** 실시간 조회가 아니므로 확정가처럼 보이면 사용자를 오도한다.
- **예약과 결제는 제공하지 않는다.** 제품 경계상 정보 제공까지가 이 서비스의 역할이며, 예약은 사용자가 직접 진행한다.
- **국내 목적지는 다루지 않는다.** 제품 경계상 해외 여행지로 한정한다.

## 가정

되돌리기 쉬운 판단이며, 다르게 원하시면 언제든 바꿀 수 있다.

- 초기 목적지는 동남아 4개국(필리핀 3, 태국 3, 말레이시아 2, 인도네시아 4)의 주요 다이빙 지역 12곳으로 시작한다. 목적지 추가는 데이터만 늘리면 되는 작업이다.
- 컨디션 등급은 세 단계(최적 / 양호 / 비추천)로 매기고, 세 등급 모두 항상 표시하되 추천(최적·양호)과 비추천을 구획으로 나눠 구분한다.
- 다이빙 횟수 기본값은 이동에 앞뒤 하루씩을 쓰고 남은 날에 하루 3다이브를 적용해 추정한다.
- 여행 월은 한 번에 하나만 선택한다. 여러 달 비교는 조건을 바꿔가며 수행한다.
- 금액은 원화로 표시한다.
- 지역 필터는 국가 단위로 제공한다.

## 범위 밖

- **예약·결제 연동** — 제품 경계에서 명시적으로 제외했다. 사용자가 직접 예약한다.
- **실시간 항공권 조회** — 데이터 소스 결정에서 정적 데이터로 통일했다.
- **국내 다이빙 목적지** — 제품 경계에서 제외했다.
- **사용자 계정과 계획 저장** — 이번 조각은 한 세션 안에서 후보를 좁히는 흐름까지만 다룬다.
- **교육 과정(자격증 코스) 정보** — 주 사용자가 어드밴스드 자격증 보유자다.

## 미룬 결정

- 동남아 외 지역(중동, 태평양 도서국) 확장 시점과 기준.
- 데이터 갱신 주기와 담당 방식. 지금은 수동 갱신이라는 것까지만 정했다.
- 확정한 여행 계획을 내보내거나 공유하는 방법.

## 남은 위험

- **데이터 조사 품질이 결과물의 신뢰도를 그대로 결정한다.** 목적지별 요금은 대표 다이빙샵 2～3곳의 공시 요금을 기준으로 삼는데, 실제 시장가와 차이가 클 수 있다. 요금대 표기와 기준 시점 노출로 완화하지만 없애지는 못한다.
- **항공 요금대의 변동 폭이 크다.** 성수기·비수기 차이와 항공사별 격차가 커서 요금대가 넓어지면 비교 기준으로서의 유용성이 떨어질 수 있다. 실제 데이터를 채운 뒤 확인이 필요하다.
- **컨디션 등급의 근거가 주관적일 수 있다.** 시야·수온·조류를 종합해 등급을 매기는 기준이 조사자마다 흔들리면 목적지 간 비교가 왜곡된다.
