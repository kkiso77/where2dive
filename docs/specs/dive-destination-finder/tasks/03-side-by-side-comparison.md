# 03 — 후보지 나란히 비교

## Outcome

사용자가 후보지 두 곳 이상을 골라 컨디션, 다이빙 스타일, 비용 항목이 같은 축에 정렬된 비교 화면을 본다. 조건을 바꿔도 골라둔 비교 대상은 유지되며, 새 조건에서 후보 목록에서 빠진 목적지는 제외됐다는 사실이 드러난다.

## Blockers

02 — 비교 축에 비용 항목이 들어가야 하므로 견적 산출이 먼저 있어야 한다.

## Acceptance criteria

- [x] 후보지 두 곳 이상을 선택하면 컨디션·스타일·비용 항목이 같은 축에 정렬된 비교 화면을 볼 수 있다.
- [x] 조건을 바꾼 뒤에도 선택해둔 비교 대상이 유지된다.
- [x] 새 조건에서 비교 대상 목적지가 지역·스타일 필터에 걸려 후보에서 완전히 빠지면 그 사실이 드러나고, 후보에는 남아 있지만 비추천으로 바뀐 경우는 그와 구분되게 드러난다.
- [x] 비교 대상에서 개별 목적지를 뺄 수 있고, 한 곳 이하로 줄면 비교 화면이 닫힌다.

## Constraints

- 비교 대상은 한 세션 안에서만 유지된다. 사용자 계정이나 영구 저장은 이 작업의 범위가 아니다.

## Verification

- E2E: 목적지 두 곳을 선택해 비교 화면을 연 뒤 여행 월을 바꾸면 두 곳이 그대로 비교 화면에 남아 있다.
- E2E: 새 조건에서 필터에 걸려 후보에서 빠진 목적지에는 "후보 아님" 표시가, 비추천으로 바뀐 목적지에는 그와 구분되는 표시가 붙는다.
- E2E: 비교 대상을 한 곳으로 줄이면 비교 화면이 닫힌다.
