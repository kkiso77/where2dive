# 01 — 시기별 후보지 탐색

## Outcome

사용자가 여행 월, 여행 기간, 지역, 다이빙 스타일 관심사를 지정하면 조건에 맞는 다이빙 목적지가 지도 마커와 카드 목록에 함께 표시된다. 카드 목록은 국가별로 묶이고 국가 그룹은 접었다 펼 수 있으며, 그룹 내부는 인천에서 가까운 순으로 정렬된다. 그 달에 다이빙하기 좋은 추천 목적지와 조건이 안 맞는 비추천 목적지가 각각 별도 구획으로 항상 함께 표시된다. 각 카드는 해당 월의 컨디션 등급과 그 판단 이유, 다이빙 스타일 특성, 공항에서 다이빙 지역까지 가는 이동 방법 요약을 보여주고, 목적지의 다이빙샵은 구글맵 장소 링크로 연결된다. 조건을 바꾸면 페이지 이동 없이 결과만 갱신된다.

동남아 목적지의 큐레이션 데이터 조사가 이 결과에 포함된다. 데이터만으로는 사용자가 아무것도 할 수 없으므로 이 결과에 접었다.

## Blockers

None.

## Acceptance criteria

- [x] 여행 월과 기간을 입력하면 해당 월에 다이빙 가능한 목적지가 인천에서 가까운 순으로 지도와 목록에 함께 표시된다.
- [x] 같은 목적지가 지도 마커와 카드 목록 양쪽에 나타나며, 한쪽에서 선택하면 다른 쪽에서도 선택 상태가 드러난다.
- [x] 다이빙 스타일 관심사(초급자 추천, 조류, 드리프트, 대물, 매크로)로 후보지를 걸러낼 수 있고, 걸러낸 결과가 지도와 목록에 동시에 반영된다.
- [x] 지역 필터로 국가 단위 범위를 좁힐 수 있다.
- [x] 조건에 맞는 목적지가 하나도 없으면 그 사실과 조건을 어떻게 바꾸면 되는지가 안내된다.
- [x] 각 목적지의 다이빙샵 정보는 구글맵 장소 링크로 연결되어 사용자가 직접 확인할 수 있다.
- [x] 조건을 바꿔도 페이지가 이동하지 않고 결과만 갱신된다.
- [x] 후보지는 국가별로 묶여 표시되고, 국가 그룹은 접었다 펼 수 있다.
- [x] 그 달에 다이빙하기 좋은 추천 목적지와 조건이 안 맞는 비추천 목적지가 별도 구획으로 항상 함께 표시된다. 지역·스타일 필터로 아예 걸러진 목적지와는 구분된다.
- [x] 각 카드에 해당 월에 그 컨디션 등급을 받은 이유가 한 줄로 표시된다.
- [x] 각 카드에 공항에서 다이빙 지역까지 가는 이동 수단과 소요 시간이 요약으로 표시된다.

## Constraints

- 목적지 데이터는 저장소 안의 큐레이션 데이터에서 온다. 외부 API를 실시간으로 호출하지 않는다.
- 지도는 Leaflet과 OpenStreetMap 타일로 그린다. 구글맵은 외부 링크로만 쓴다.
- 초기 데이터 범위는 동남아 4개국(필리핀 3, 태국 3, 말레이시아 2, 인도네시아 4)의 주요 다이빙 지역 12곳이다.
- 데이터에는 각 목적지·월 조합의 컨디션 판단 이유, 공항에서 다이빙 지역까지의 이동 방법을 담는다.
- 데이터에는 이후 견적 산출에 필요한 요금 정보(다이빙 요금 구간표, 장비 대여료, 리브어보드 운항 시즌과 요금대, 인천 출발 항공 요금대·경유 공항·최종 목적지 공항, 숙소 두 유형의 요금대)를 함께 담는다. 이 작업에서는 화면에 노출하지 않는다.
- 승인된 화면 구조와 동작은 [prototype.html](../prototype.html)을 근거로 삼는다.
