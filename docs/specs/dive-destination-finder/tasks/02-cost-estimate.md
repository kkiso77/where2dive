# 02 — 예상 견적 산출

## Outcome

후보지를 선택하면 예상 견적이 항목별로 펼쳐진다. 여행 기간에서 추정된 다이빙 횟수가 기본값으로 제시되고, 사용자가 조정하면 총액이 즉시 바뀐다. 다이빙 비용은 1～2회, 3～4회, 5～9회, 10회 이상 네 구간의 전체 요금표로 제시되고 현재 적용된 구간이 표시된다. 장비 대여료, 리브어보드 옵션, 인천 출발 항공 요금대(경유 시 경유 공항과 최종 목적지 공항), 공항에서 다이빙 지역까지 가는 구체적인 이동 방법, 숙소 두 유형이 각각 별도 항목으로 표시된다. 카드 목록에도 예상 총비용 요약이 붙는다.

## Blockers

01 — 후보지를 고르는 화면과 요금 데이터가 있어야 견적이 성립한다.

## Acceptance criteria

- [x] 여행 기간을 입력하면 이동일을 제외한 다이빙 횟수 기본값이 제시되고, 그 값을 조정하면 견적 총액이 즉시 바뀐다.
- [x] 다이빙 비용 구간표(1～2회, 3～4회, 5～9회, 10회 이상)가 전체로 표시되고, 현재 다이빙 횟수에 적용된 구간이 표시된다.
- [x] 후보지를 선택하면 다이빙 비용, 장비 대여료, 항공 요금대, 숙소 요금대가 각각 별도 항목으로 표시된다.
- [x] 리브어보드가 운항하는 목적지에서는 리브어보드 옵션과 요금대가 표시되고, 운항하지 않는 목적지에서는 해당 항목이 나타나지 않는다.
- [x] 리브어보드가 운항하는 목적지에서는 "리브어보드 이용 시 예상 총액"(항공 + 리브어보드 패키지)이 육상 기준 예상 총액과는 별도의 금액으로 표시되며, 두 총액은 서로 합산되지 않는다.
- [x] 숙소는 다이빙샵 패키지 포함형과 별도 숙박형이 각각 구분되어 표시된다.
- [x] 항공 요금대는 인천 출발 기준이며, 직항이면 직항으로, 경유가 필요하면 경유 공항과 최종 목적지 공항이 함께 표시된다.
- [x] 공항에서 다이빙 지역까지 가는 이동 수단과 소요 시간이 구체적으로 표시된다.
- [x] 모든 금액에 조사 시점 기준의 참고가라는 점과 그 기준 시점이 함께 표시된다.
- [x] 카드 목록의 각 후보지에 현재 조건 기준 예상 총비용이 요약되어 나타난다.

## Constraints

- 금액은 단일 확정값이 아니라 요금대로 제시한다.
- 금액은 원화로 표시한다.
- 다이빙 횟수 기본값은 이동에 앞뒤 하루씩을 쓰고 남은 날에 하루 3다이브를 적용해 추정한다.
- 리브어보드는 해당 목적지의 운항 시즌에 여행 월이 포함될 때만 옵션으로 제시한다.
- 승인된 화면 구조와 동작은 [prototype.html](../prototype.html)을 근거로 삼는다.

## Verification

- E2E: 다이빙 횟수를 4구간 경계 아래에서 위로 올리면 1다이브 단가가 낮아지고 적용된 구간이 요금표에서 강조 표시된다.
- E2E: 리브어보드가 없는 목적지를 선택하면 리브어보드 항목이 화면에 없다.
- E2E: 경유 목적지를 선택하면 경유 공항과 최종 목적지 공항이 함께 표시되고, 공항에서 다이빙 지역까지의 이동 방법이 나타난다.
- E2E: 여행 기간을 5일로 입력하면 다이빙 횟수 기본값이 9로 제시된다.
- 단위: 알려진 요금표와 다이빙 횟수 조합에 대해 견적 총액이 기대값과 일치한다.
- 단위: 여행 기간에서 다이빙 횟수를 추정하는 계산이 이동일을 제외한 결과를 낸다. 이동일보다 짧은 기간에서도 음수가 나오지 않는다.
